# Shop Autopilot — ছবি থেকে ওয়েবসাইট, ক্রিয়েটিভ, ফেসবুক পোস্ট আর অ্যাড

একটা প্রোডাক্টের ছবি তুলুন বা আপলোড করুন। বাকি কাজ সিস্টেম নিজেই করবে:

```
📷 ছবি ─► ✂️ ব্যাকগ্রাউন্ড রিমুভ ─► 🤖 AI প্যাকেট পড়ে তথ্য বের করে
        (নাম, ব্র্যান্ড, ক্যাটাগরি, মেয়াদ, সাইজ, MRP, বিবরণ, উপাদান…)
   ─► 🛒 ওয়েবসাইটে প্রোডাক্ট পেজ তৈরি
   ─► 🎨 AI ক্রিয়েটিভ (৩টি স্টাইল, 1080×1080)
   ─► ✍️ ফেসবুক ক্যাপশন (বাংলা/English, লিংকসহ)
   ─► 📅 ফেসবুক পেজে পোস্ট (এখনই বা শিডিউল করে)
   ─► 📣 সেই পোস্ট থেকে অ্যাড চালু: বাজেট $, শুরু-শেষ তারিখ, আর অডিয়েন্স নিজের ভাষায় লিখলেই হবে
```

দুইভাবে চালানো যায়:

- **⚡ Autopilot:** একটা ফর্মে ছবি, দাম, অফার, পোস্টের সময়, বাজেট, তারিখ আর অডিয়েন্স দিন। এক ক্লিকে উপরের সব কাজ হয়ে যাবে।
- **ধাপে ধাপে:** প্রতিটি ধাপ দেখে, এডিট করে তারপর এগোবেন। AI যেসব তথ্য নিশ্চিতভাবে পড়তে পারেনি, সেগুলো হলুদ রঙে "যাচাই করুন" দেখাবে।

**পণ্য / পোস্ট / অ্যাড** ট্যাবে সব প্রোডাক্ট, শিডিউল করা পোস্ট আর চলমান অ্যাড দেখা যায়। সেখান থেকে অ্যাডের খরচ, রিচ আর ইমপ্রেশন দেখা যায়, অ্যাড Pause/Resume করা যায়।

## চালু করা

Node.js 22 বা নতুন ভার্সন লাগবে।

```bash
cd app
npm install
cp .env.example .env      # তারপর .env খুলে key-গুলো বসান
npm start
```

- শপ: `http://localhost:3000/`
- অ্যাডমিন প্যানেল: `http://localhost:3000/admin/`

মোবাইলে অ্যাডমিন প্যানেল খুলে "📷 ছবি তুলুন" চাপলে সরাসরি ফোনের ক্যামেরা খুলবে।

### ডেমো মোড

`.env`-এ ফেসবুকের কোনো key না দিলে সিস্টেম **ডেমো মোডে** চলবে। তখন পুরো ফ্লো কাজ করবে, কিন্তু ফেসবুকে কিছু পোস্ট হবে না এবং কোনো টাকা খরচ হবে না। যা পাঠানো *হতো*, সেটা সার্ভারের লগে দেখা যাবে। শুধু `ANTHROPIC_API_KEY` দিলেই ছবি থেকে তথ্য বের করা, ক্রিয়েটিভ আর ক্যাপশন পরীক্ষা করা যায়।

## কোন key কোথা থেকে পাবেন

| ভেরিয়েবল | কাজ | কোথায় পাবেন |
|---|---|---|
| `ANTHROPIC_API_KEY` | ছবি পড়া, বিবরণ, ক্রিয়েটিভের লেখা, ক্যাপশন, অডিয়েন্স বোঝা | platform.claude.com → API Keys |
| `REMOVE_BG_API_KEY` (ঐচ্ছিক) | আরও দ্রুত/নিখুঁত ব্যাকগ্রাউন্ড রিমুভ | remove.bg → API। না দিলে সার্ভারেই ফ্রি AI মডেল দিয়ে রিমুভ হবে |
| `FB_PAGE_ID` | কোন পেজে পোস্ট হবে | Page → About → Page ID |
| `FB_PAGE_ACCESS_TOKEN` | পেজে পোস্ট/শিডিউল | Meta for Developers অ্যাপ → Graph API Explorer → Page token (`pages_manage_posts`, `pages_read_engagement`) → long-lived token-এ বদলে নিন |
| `FB_AD_ACCOUNT_ID` | কোন অ্যাড অ্যাকাউন্ট থেকে খরচ হবে | Ads Manager → উপরের Account ID |
| `FB_ADS_ACCESS_TOKEN` | অ্যাড তৈরি | Business Settings → System Users → token (`ads_management`, `ads_read`, `pages_read_engagement`)। পেজ আর অ্যাড অ্যাকাউন্ট দুটোই system user-কে অ্যাসাইন করতে হবে |

> **টাকার হিসাব:** বাজেট অ্যাড অ্যাকাউন্টের কারেন্সিতে ধরা হয়। অ্যাকাউন্টের কারেন্সি USD হলে "$10" মানে ঠিক $10। অন্য কারেন্সি হলে অ্যাডমিন প্যানেলের উপরে সতর্কবার্তা দেখাবে।

| ওয়েবসাইট | বিল্ট-ইন শপ: ক্যাটাগরি ফিল্টার, প্রোডাক্ট পেজ, WhatsApp/কল অর্ডার বাটন, ফেসবুক প্রিভিউর জন্য Open Graph ট্যাগ | `src/views.js` |
| ক্রিয়েটিভ | Claude হেডলাইন, ব্যাজ, CTA আর রং বেছে দেয়। sharp কাটআউট ছবি, শ্যাডো আর লেখা মিলিয়ে ৩টি টেমপ্লেট বানায় | `src/image.js` |

| অডিয়েন্স | "ঢাকার ১৮-৩৫ বছরের মেয়েরা যারা মেকআপ পছন্দ করে" লিখলে Claude সেটা বয়স, লিঙ্গ, শহর আর আগ্রহে ভাগ করে। এরপর ফেসবুক সার্চ API থেকে আসল শহর ও ইন্টারেস্ট ID বের হয় | `src/ai.js`, `src/facebook.js` |

## অনলাইনে তোলা (deploy)

- যেকোনো Node হোস্টিং চলবে: VPS, Railway, Render ইত্যাদি। `data/` আর `public/uploads/` ফোল্ডার যেন স্থায়ী (persistent) ডিস্কে থাকে।
- `PUBLIC_BASE_URL`-এ আসল ডোমেইন দিন (https)। ফেসবুক পোস্টের লিংক এখান থেকেই তৈরি হয়।
- `ADMIN_PASSWORD` অবশ্যই দিন।
- ক্রিয়েটিভে বাংলা লেখা ঠিকভাবে দেখাতে সার্ভারে বাংলা ফন্ট ইনস্টল করুন: `sudo apt install fonts-noto-core` (বা Hind Siliguri)। ফন্ট না থাকলে ক্রিয়েটিভের ভাষা English রাখুন। ক্যাপশন আর ওয়েবসাইট সবসময় বাংলায় ঠিক দেখায়।

## API (অন্য অ্যাপ বা ওয়েবসাইট থেকে ব্যবহারের জন্য)

| Method | Path | কাজ |
|---|---|---|
| POST | `/api/products/analyze` | `photos` (multipart, ১–৪টি), `price`, `hint` → ড্রাফট প্রোডাক্ট |
| PATCH | `/api/products/:id` | তথ্য এডিট |
| POST | `/api/products/:id/publish` | ওয়েবসাইটে প্রকাশ |
| POST | `/api/products/:id/creatives` | `{offer, language}` → ৩টি ক্রিয়েটিভ |
| POST | `/api/products/:id/caption` | `{tone, language, offer}` → ক্যাপশন |
| POST | `/api/posts` | `{productId, creativeUrl, message, publishAt?}` |
| POST | `/api/ads/audience` | `{text, productId}` → টার্গেটিং প্রিভিউ |
| POST | `/api/ads` | `{postId, budget, budgetType: lifetime\|daily, startTime, endTime, audience, goal: engagement\|reach}` |
| POST | `/api/ads/:id/pause` · `/resume` · `/retry` | অ্যাড নিয়ন্ত্রণ |
| GET | `/api/public/products` | পাবলিক প্রোডাক্ট লিস্ট (WooCommerce/Shopify বা অন্য সাইটে সিঙ্ক করার জন্য) |

`ADMIN_PASSWORD` দেওয়া থাকলে `/api/*` রুটগুলোতে Basic Auth লাগবে। শুধু `/api/public/*` খোলা থাকে।

## সতর্কতা

- AI-এর বের করা তথ্য, বিশেষ করে **মেয়াদের তারিখ আর দাম**, প্রকাশের আগে একবার চোখে দেখে নিন।
- ফেসবুকের বিজ্ঞাপন নীতিমালা মেনে চলুন। স্বাস্থ্য বা "গ্যারান্টিড ফল" ধরনের দাবি থাকলে অ্যাড রিজেক্ট হতে পারে। ক্যাপশন লেখার সময় AI-কে এসব দাবি এড়াতে বলা আছে।
- আসল মোডে অ্যাড চালুর আগে প্যানেল বাজেট নিশ্চিত করতে চায়।
